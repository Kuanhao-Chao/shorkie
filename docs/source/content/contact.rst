Contact
=======

Bugs, questions, feature requests
---------------------------------

Please open a `GitHub issue <https://github.com/calico/shorkie-paper/issues>`_.
It helps enormously to include:

* the exact command or code you ran
* the full traceback
* how you obtained the weights (``data/download.sh``, direct link, retrained)
* your OS, Python, and TensorFlow versions
