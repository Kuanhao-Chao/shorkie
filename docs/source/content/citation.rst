Citation
========

If you use Shorkie, please cite the preprint:

   Chao, K.-H., Magzoub, M. M., Stoops, E. H., Hackett, S. R., Linder, J., &
   Kelley, D. R. (2025). *Predicting dynamic expression patterns in budding yeast
   with a fungal DNA language model.* bioRxiv.
   https://doi.org/10.1101/2025.09.19.677475

The repository also ships a `CITATION.cff
<https://github.com/calico/shorkie-paper/blob/main/CITATION.cff>`_, so GitHub's
"Cite this repository" button produces the same reference.
